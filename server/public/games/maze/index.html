投影回廊 · Perspective Corridor

一款纪念碑谷式的 2D↔3D 视角迷宫。规则很简单：在当前视角里，看起来挨着、走得过去的地砖，就真的能走。
· 3D 等距：顶面同色且四邻连成一片才是同一平面，可在上面走；同色但不相连不能直达。侧面露出墙色的高差，3D 里爬不上去——请切俯视。远处对齐可跨（金色光带）。
· 2D 俯视：世界被压成平面，脚印相邻都能走——含一切高差；青色幽灵桥也只在俯视里是实体。
按 空格 在俯视与 3D 之间翻转；多方位章节再用 Q / E（或两侧按钮）转动 3D 卦限——同一座浮砖，换个方位才会对齐成桥。主角不会跳跃，全程贴地行走；可用 WASD 移动（A/D 原地左转/右转，W/S 沿面朝前进/后退；点按一格或一转、长按连走连转），或点地砖寻路；途中可右键 / Esc 停步，或再点地砖改道。

游戏模式：进入时可选难度。观光模式无影怪、无佩剑、无血量限制（正篇），从第 0 关机能试验场启程——试验场内仍可测影怪 / 大剑 J / 心与坠落，以及青桥·金桥·假台·齿轮转盘·序星·Q/E 方位·攀高·WASD；再入正篇后恢复纯观光。踏空在正篇只回起点。屠戮模式背负大剑、廊中有影，出生与终点对调，从终章倒行回第一章（试验场不计入倒行），全局限时 5 分钟。可在账号菜单中重新选择模式。

生命（仅屠戮模式）：右上角三颗心。站在仅 3D 或仅俯视才实体的地砖上、或 3D 悬空高台上，再切到另一视角，若新视角里脚下没有实体，会踏空坠落，失去一颗心，并从本章出生点重来。三心耗尽后生命回满，仍从本章重开。按 R 重玩会补满生命 · 右上角可调画质（卡顿请选「流畅」）与音量 · M 静音。

影怪与大剑（仅屠戮模式）：每关固定刷新 2 只影怪（出生点 4 格外、位置固定）。进入其视野会从侧翼追杀；碰到会扣一颗心，但不会送回出生点——扣血特效期间时间冻结，特效结束小怪才再动。三心耗尽则本章重开，影怪一并刷新。影怪同样受视角/齿轮机关影响，踏空坠落即永久消失（直到重开本章）。主角背负大剑：仅按 J 攻击（扇形朝眼睛看的方向，有前摇与后摇）；一刀可斩杀。影怪会在前摇时侧闪躲避。

齿轮与错觉：齿轮带动平台转向；一转之后，远处的砖可能在画面上恰好对齐，虚影便成了实路（对齐处亮金色光带）。侧面有色差、须俯视翻过的高差，会亮青色光带。接通错觉时会有轻声与字条提醒。站在转动的平台上，还会被它一同带走。

建筑师留言：每一章都藏有一块石碑旁支。右上角 ◈ 统计已读篇数；正篇碑文全部读过，并通关第十三章，会开启隐藏外章。

账号与存档：仅主机双击「启动游戏.bat」。玩完关掉本机游戏网页即可自动清后台（也会启动「关闭游戏.bat」）；也可在启动窗按任意键。其它电脑请用「访客联机.bat」或浏览器打开 http://主机IP:8940/，不要在访客机再启动本地服务。有 Node 为在线模式（进度写入 data/db.json）；没有 Node 则为离线游客（进度仅本机浏览器）。
