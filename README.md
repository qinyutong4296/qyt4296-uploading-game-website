# 小游戏网站

这是一台在你电脑上跑的网站，**不需要 Cursor、也不需要跟 AI 对话**。用 Chrome 或 Edge 打开即可。

## 怎么打开（Windows）

1. 电脑已安装 [Node.js LTS](https://nodejs.org)（没有的话先装，装完重新打开一次命令行）。
2. 双击项目文件夹里的 **`启动网站.bat`**。
3. 等待依赖检查与打包完成，浏览器会自动打开 [http://localhost:8080](http://localhost:8080)。
4. 关站任选其一即可（会一并结束后台进程，并自动关掉启动用的终端窗口）：
   - **关掉本机打开的网站标签页/窗口**（推荐）；或
   - 直接关闭启动时的黑窗口；或
   - 双击 **`关闭网站.bat`**。
   
   刷新页面不会关站；局域网其它设备关掉自己的网页也不会影响主机。
   两个防误关保护：网站刚启动后的约 12 秒内，关掉网页不会停服（此时后台可能还残留旧标签页）；开有多个本机标签页时，只关其中一个也不会停服，关掉**最后一个**标签页才会清后台。

若窗口已经在跑、只想再打开页面：浏览器访问 [http://localhost:8080](http://localhost:8080) 即可。

管理员：首次启动若还没有管理员账号，会自动创建 `admin` 并在黑窗口打印一次随机初始密码（也可用环境变量 `ADMIN_PASSWORD` 指定）→ 登录后侧栏「管理后台」，或直接打开 `/admin`(本机账号体系,数据存本机 SQLite,实时监控在线对局、隐藏/删除游戏、强制结束会话)

同一 WiFi 下的手机也可以访问，看黑窗口里打印的 `http://192.168.x.x:8080`。

## 命令行（可选）

```bash
npm run install:all
npm run web
```

开发热更新（改代码立刻刷新）：

```bash
npm run dev
```

然后打开 http://localhost:5173

## 使用说明

游客不用注册也能进：登录页点「游客进入 · 进度保存在本机」，本机会自动建一个游客账号并记住它。
大厅可以先逛。点进游戏、上传自己的小游戏、看个人资料需要登录。
登录后在「上传游戏」选择整个游戏文件夹；系统会自动识别入口页，并在大厅显示打开方式。
侧栏「留言板」：登录用户与游客都可以留言，每人可删自己的留言，管理员可删任何留言。
管理员可在后台实时监控在线对局、隐藏/删除游戏，并强制结束玩家会话。

内置游戏含「投影回廊」（原桌面「迷宫」）：静态资源在 `server/public/games/maze/`，大厅点击即可全屏开玩。BGM 与存档目录通过联接指向桌面「迷宫」的 `audio` / `data`，登录进度与桌面版互通。本站提供迷宫同源 API（`/api/ping`、`/api/login` 等），游戏内注册/登录/游客与单机一致。
